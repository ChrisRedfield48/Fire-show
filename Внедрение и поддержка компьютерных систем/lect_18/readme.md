## Дистрибутивы Linux

**Дистрибутив** — готовая сборка Linux с программой установки, набором программ и настройками по умолчанию.

- Каждый дистрибутив имеет **свою программу установки**, но назначение у всех одинаковое
- Дистрибутивы отличаются набором программ и настройками по умолчанию
- Обычный пользователь может установить рабочую систему, не задумываясь о деталях

**Ubuntu** — самый популярный дистрибутив Linux. Слоган: *«Linux для людей»*.

## Файловая система

| Понятие | Описание |
|---|---|
| **Корневая папка** | Всегда только одна — все остальные папки вложены в неё. Файловая система представляет собой единое дерево |
| **Монтирование** | Подключение файловой системы с другого устройства в одну из папок текущего дерева |
| **Точка монтирования** | Пустая папка, в которую монтируется файловая система |
| **Размонтирование** | Отключение смонтированной системы; папка-точка монтирования снова становится пустой |
| **Автомонтирование** | При загрузке системы все устройства монтируются автоматически; при остановке — размонтируются |

**Основная файловая система:** `ext3` (журналируемая) — размер кластера от 1 до 8 КБ.

## Преимущества Linux перед Windows

| Параметр | Windows | Linux |
|---|---|---|
| **Безопасность** | Основная цель вирусов и вредоносных программ | Около 10 вирусов; ни один не способен поразить систему в целом |
| **Надёжность** | Частые сбои, потеря данных | Бесперебойная работа годами без переустановки |
| **Стоимость** | Высокая стоимость лицензии | Бесплатная |
| **Системные требования** | Растут с каждой новой версией | Невысокие — работает даже на старом железе |
| **Обновления** | Только с серверов Microsoft | Регулярные новые версии ПО + доступ к исходным кодам |
| **Исходный код** | Закрытый | Открытый |
| **Лицензия** | Нельзя копировать, передавать, использовать на нескольких ПК | Можно свободно копировать, скачивать, модифицировать и переиздавать |
