## Теоретическая часть

### Файловая структура Linux

В Linux файлами считаются:
- Обычные файлы
- Каталоги
- Специальные файлы (каждое устройство представляется в виде файла)

Файловая структура имеет **иерархическую древовидную структуру** с единственным корневым каталогом `/`.

### Основные каталоги корневой директории

| Каталог | Назначение |
|---|---|
| `/bin` | Выполняемые командные программы и shell-процедуры |
| `/tmp` | Временные файлы |
| `/usr` | Каталоги пользователей |
| `/etc` | Административные утилиты и файлы |
| `/dev` | Специальные файлы периферийных устройств |

### Обозначения каталогов

| Обозначение | Значение |
|---|---|
| `.` | Текущий каталог |
| `..` | Родительский каталог |
| `/` | Корневой каталог |

### Права доступа к файлам

В Linux различаются **3 уровня доступа**:

1. Владелец файла (`u`)
2. Группа пользователей (`g`)
3. Остальные пользователи (`o`)

**Символы прав:**

| Символ | Значение |
|---|---|
| `r` | Чтение |
| `w` | Запись |
| `x` | Выполнение |
| `-` | Отсутствие разрешения |

**Первый символ атрибутов — тип файла:**

| Символ | Тип |
|---|---|
| `-` | Обычный файл |
| `d` | Каталог |
| `l` | Символическая связь |
| `b` | Блок-ориентированный специальный файл |
| `c` | Байт-ориентированный специальный файл |

**Формат вывода `ls -l`:**

```
d  rwx  rwx  rwx
│   │    │    └─ Доступ для остальных пользователей
│   │    └────── Доступ для членов группы
│   └─────────── Доступ владельца
└─────────────── Тип файла
```

### Основные команды

| Команда | Описание |
|---|---|
| `echo "текст" > файл` | Создание файла с содержимым |
| `cat файл` | Вывод содержимого файла |
| `cat f1 f2 > f3` | Конкатенация (объединение) файлов |
| `mv f1 f2` | Переименование файла |
| `mv f1 f2 dir` | Перемещение файлов в каталог |
| `cp f1 f2` | Копирование файла |
| `rm f1 f2` | Удаление файлов |
| `mkdir dir` | Создание каталога |
| `cd dir` | Переход в каталог |
| `pwd` | Вывод текущего каталога |
| `ls -l` | Полный листинг с атрибутами |
| `chmod` | Изменение прав доступа |
| `ln f1 f2` | Создание жёсткой связи |
| `ln -s f1 f2` | Создание символической связи |
| `grep шаблон файл` | Поиск по шаблону |

**Команда `chmod` — примеры:**

```bash
chmod g+rw,o+r file.1    # добавить права чтения/записи группе и чтения остальным
chmod o-w file.1          # отменить запись для остальных
chmod 755 file1.txt       # числовой формат: владелец=7(rwx), группа=5(r-x), остальные=5(r-x)
```

### Шаг 7. Добавление права выполнения

Попытки с неверным синтаксисом:

```bash

chmod g+x,O+x file1.txt file2.txt file_combined.txt   # ошибка: 'O' должно быть 'o'
```

Успешная установка прав числовым методом:

```bash
chmod 755 file1.txt
```

## Контрольные вопросы

### 1. Что считается файлами в ОС Linux?

В Linux файлами считаются три категории объектов: **обычные файлы** (документы, программы, данные), **каталоги** (директории, содержащие ссылки на другие файлы), а также **специальные файлы** — представления периферийных устройств (принтеры, диски, терминалы). Такой подход обеспечивает единообразный доступ ко всем объектам системы.

### 2. Назначение связей с файлами и способы их создания

**Связь (link)** позволяет одному файлу принадлежать нескольким каталогам одновременно — то есть иметь разные имена в разных местах файловой системы.

| Тип связи | Команда | Особенности |
|---|---|---|
| **Жёсткая** | `ln file1 file2` | Оба имени равнозначны; файл удаляется только после удаления всех ссылок |
| **Символическая** | `ln -s file1 file2` | `file2` — указатель на `file1`; при выводе отображается содержимое оригинала |

### 3. Атрибуты файлов — просмотр и изменение

**Просмотр:** `ls -l` — выводит строку атрибутов формата `drwxrwxrwx`, число связей, владельца, размер, дату и имя.

**Изменение:** команда `chmod` в двух форматах:

```bash
# Символьный формат
chmod u+x file        # добавить выполнение владельцу
chmod g-w,o-w file    # убрать запись у группы и остальных

# Числовой (восьмеричный) формат
chmod 755 file        # rwxr-xr-x
chmod 644 file        # rw-r--r--
```

### 4. Методы создания и удаления файлов и каталогов

**Создание:**

```bash
> file.txt              # создать пустой файл
echo "текст" > file.txt # создать файл с содержимым
touch file.txt          # создать пустой файл
mkdir dirname           # создать каталог
```

**Удаление:**

```bash
rm file1 file2    # удалить файлы
rm -r dir         # удалить каталог рекурсивно
rmdir dir         # удалить пустой каталог
```

### 5. Поиск по шаблону (grep)

`grep` — утилита поиска строк, соответствующих заданному шаблону.

```bash
grep -l student *.txt      # имена файлов .txt, содержащих слово "student"
who | grep tty23           # найти пользователя, работающего на терминале tty23
grep -n "error" log.txt    # вывести строки с "error" с нумерацией
grep -i "linux" file.txt   # поиск без учёта регистра
```

**Ключи grep:**

| Ключ | Действие |
|---|---|
| `-v` | Строки, **не** содержащие шаблон |
| `-c` | Только количество совпадающих строк |
| `-i` | Игнорировать регистр |
| `-l` | Только имена файлов с совпадениями |
| `-n` | Пронумеровать выводимые строки |

### 6. Список работающих пользователей с сохранением в файл

```bash
who > users.txt
```

Команда `who` выводит список всех пользователей, активных в системе. Символ `>` перенаправляет вывод в файл `users.txt`. Для просмотра:

```bash
cat users.txt
```
