# Лабораторная работа №15
## Установка и настройка центра обновления Windows

**Цель:** Изучить принципы настройки и обновления ОС Windows 10.

---

## Ход выполнения работы

### 1. Настройка центра обновления Windows 10

Переход: **Пуск → Параметры → Обновление и безопасность → Центр обновления Windows.**

Нажата кнопка «Проверить наличие обновлений» — система произвела поиск доступных обновлений.

---

### 2. Проверка наличия обновлений

После проверки были обнаружены:

- **Важные (обязательные)** — обновления безопасности и критические исправления
- **Необязательные** — обновления драйверов и дополнительных компонентов

Обязательные обновления зафиксированы через: Параметры → Обновление и безопасность → **Просмотр журнала обновлений**.

---

### 3. Установка обновлений и журнал

Дождано завершения скачивания и установки обновлений. В журнале зафиксированы успешно установленные пакеты обновлений безопасности — статус каждого: **«Успешно установлено»**.

---

### 4. Отключение обновлений через редактор групповой политики

1. Открыт редактор: `Win+R` → `gpedit.msc`
2. Путь: **Конфигурация компьютера → Административные шаблоны → Компоненты Windows → Центр обновления Windows**
3. Параметр **«Настройка автоматического обновления»** → установлено значение **«Отключено»**

После закрытия редактора в Центре обновления появилось сообщение: *«Некоторыми параметрами управляет ваша организация»*. Автоматическая проверка обновлений отключена.

---

### 5. Ручная установка обновлений из папки

В проводнике выполнено подключение к сетевой папке `\\kbastrikin`. Файлы обновлений (`.msu` / `.cab`) скопированы и установлены вручную двойным кликом.

Тип каждого обновления определён через [catalog.update.microsoft.com](http://www.catalog.update.microsoft.com).

| Номер обновления | Классификация | Версия | Размер |
|---|---|---|---|
| KB5031356 | Обновление безопасности | Windows 10 21H2 | 452 МБ |
| KB5028166 | Критическое обновление | Windows 10 22H2 | 38 МБ |
| KB5026361 | Пакет обновлений (SP) | Windows 10 21H2 | 612 МБ |

---

### 6. Настройка центра обновления как службы

Путь: **Панель управления → Администрирование → Управление компьютером → Службы и приложения → Службы**

Найдена служба **«Центр обновления Windows»** (`wuauserv`). В свойствах:

- **Вкладка «Общие»:** тип запуска → **«Вручную»**
- **Вкладка «Восстановление»:** при первом и втором сбое — «Перезапуск службы» (задержка 1 мин); при последующих — «Перезагрузка компьютера»

Параметры сохранены: **Применить → ОК**.

## Контрольные вопросы

### 1. Что такое обновление?

Обновление — пакет исправлений, дополнений или улучшений для ПО, выпускаемый разработчиком с целью устранения ошибок, закрытия уязвимостей, повышения стабильности и функциональности системы. В Windows обновления распространяются через службу Windows Update и могут устанавливаться автоматически или вручную.

---

### 2. Типы обновлений Windows

| Тип | Описание | Установка |
|---|---|---|
| Важные | Обновления безопасности и критические исправления | Автоматически |
| Рекомендуемые | Некритические улучшения работы системы | Авто / вручную |
| Необязательные | Драйверы, языковые пакеты, доп. компоненты | Только вручную |
| Обновления безопасности | Исправление конкретных уязвимостей (критическая / важная / средняя / низкая) | Автоматически |
| Критические обновления | Исправление серьёзных ошибок, не связанных с безопасностью | Автоматически |
| Пакеты обновлений (SP) | Накопительные сборки всех ранее выпущенных исправлений + новые улучшения | Автоматически |

---

### 3. Центр обновления Windows

**Центр обновления Windows (Windows Update)** — встроенный компонент ОС для автоматического получения, установки и управления обновлениями от Microsoft.

Возможности:
- Автоматически проверять и устанавливать обновления
- Просматривать журнал установленных обновлений
- Настраивать время и режим автообновления
- Управлять необязательными обновлениями и драйверами
- Откладывать обновления (Pro / Enterprise)

Служба Windows Update (`wuauserv`) управляется через оснастку **«Службы»**. Автоматическое обновление отключается через `gpedit.msc`.
