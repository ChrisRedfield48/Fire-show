# Центр обновления Windows

## Что такое центр обновления Windows?

**Центр обновления Windows (Windows Update)** — услуга от Microsoft, обеспечивающая обновления для ОС Windows и её компонентов.

- Обновления безопасности выходят **каждый второй вторник** месяца
- Критические обновления могут выходить в любое время — для предотвращения вирусных эпидемий

---

## История

| Период | Событие |
|---|---|
| **Windows 98 (1998)** | Windows Update впервые появился как веб-сайт. Предлагал темы, игры, драйверы и доп. компоненты |
| **После 1998** | Выпущен **Critical Update Notification Tool** — инструмент автоматической проверки критических обновлений каждые 5 минут |
| **1999–2000** | Critical Update Notification Tool продолжал обновляться |
| **2005 (RSA Conference)** | Анонсирована бета **Microsoft Update** — расширение Windows Update с поддержкой других продуктов Microsoft |
| **Windows 10** | Новый интерфейс и логотип; обновления теперь загружаются **автоматически** в любом случае |

---

## Что такое обновление?

> **Обновление** — приложение к программному обеспечению, которое предупреждает или устраняет неполадки, улучшает производительность компьютера или расширяет его возможности.

---

## Виды обновлений

Обновления для Windows разрабатываются постоянно. Каждое обновление получает порядковый номер (KB-номер), описание изменений и публикуется на официальном сайте Microsoft.

### 1. Важные (Критические)
Касаются безопасности данных пользователя и компьютера в целом. Без них компьютер остаётся незащищённым даже при наличии антивирусных программ.

### 2. Основные
Новые версии системных файлов, составляющих основу Windows. Без их установки могут быть недоступны некоторые функции или не будут устанавливаться более поздние обновления.

### 3. Рекомендуемые
Новые версии драйверов и обновления для встроенных программ Windows — браузера, медиаплеера и др.

### 4. Необязательные
Обновления, от которых практически не зависит работа системы (например, файлы поддержки языков).
