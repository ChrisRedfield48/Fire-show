# Лабораторная работа №18
## Восстановление работы системы через безопасный режим

**Цель:** Изучить принцип восстановления работы ОС Windows в безопасном режиме.

---

## Теоретическая часть

**Безопасный режим** — способ загрузки ОС, при котором загружаются только минимально необходимые компоненты системы (без фоновой картинки рабочего стола, без автозагрузки).

**Что можно делать в безопасном режиме:**

| Задача | Описание |
|---|---|
| **Проверка на вирусы** | Вирусы из автозагрузки не запускаются → антивирус может их найти и удалить |
| **Восстановление системы** | Средство восстановления работает стабильнее, если обычный режим нестабилен |
| **Установка/обновление драйверов** | Загружаются минимальные драйверы → легче устранить конфликты |
| **Диагностика** | Если в безопасном режиме проблем нет — причина в ПО; если есть — в аппаратной части |

## Ход выполнения работы

### Шаг 1. Установка загрузки в безопасный режим

1. Загружена Windows 7 в обычном режиме
2. Открыта конфигурация системы: `Win+R` → `msconfig`
3. На вкладке **«Загрузка»** в разделе «Параметры загрузки» установлена галочка **«Безопасный режим»**
4. Нажато **Применить** → **ОК** → выбрано **«Выход без перезагрузки»**

---

### Шаг 2. Создание точки восстановления системы

1. Пуск → в строке поиска введено **«Создание точки»**
2. Открылось окно **«Свойства системы»** → вкладка **«Защита системы»**
3. В разделе «Параметры защиты» нажата кнопка **«Создать»**
4. В поле названия введена фамилия и номер группы (например: *Иванов_ИС-21*)
5. Нажата кнопка **«Создать»**, дождались завершения создания точки

> Точка восстановления успешно создана.

---

### Шаг 3. Проверка созданной точки восстановления

1. Пуск → в строке поиска введено **«Восстановление»**
2. Открыто средство **«Восстановление системы»** → нажато **«Далее»**
3. В списке точек восстановления найдена созданная точка с именем (фамилия + группа)
4. Нажата кнопка **«Отмена»** — восстановление не производилось

> Точка восстановления присутствует в списке — проверка пройдена.

---

### Шаг 4. Загрузка в безопасный режим

1. Windows 7 перезагружена — загрузка в безопасный режим прошла автоматически (msconfig настроен на шаге 1)
2. Система загрузилась в безопасном режиме (отсутствует фоновый рисунок, в углах экрана надписи «Безопасный режим»)

---

### Шаг 5. Анализ точек восстановления в безопасном режиме

1. Открыто средство **«Восстановление системы»**
2. Установлена галочка **«Показать другие точки восстановления»**

> **Количество точек восстановления, созданных системой автоматически:** 3 (пример)

3. Выбрана **созданная вручную точка** → нажато **«Поиск затрагиваемых программ»**

> **Программы, которые будут удалены после применения точки:** программы, установленные после создания точки (на момент выполнения — новых установок не было, список пуст)

4. Закрыт список → выбрана **самая старая точка** → снова открыт список затрагиваемых программ

> **Отличия от новой точки:** у старой точки список затрагиваемых программ содержит больше записей, так как с момента её создания прошло больше времени и было установлено/обновлено больше компонентов системы

---

### Шаг 6. Восстановление системы

1. Выбрана точка восстановления с именем (фамилия + группа) → **«Далее»** → **«Готово»**
2. На вопрос **«Продолжить?»** нажато **«Да»**
3. Началось восстановление системы, компьютер перезагрузился
4. После перезагрузки система снова загрузилась в безопасном режиме
5. Появилось сообщение: **«Восстановление системы выполнено успешно»**

> ✅ Восстановление системы выполнено успешно.

---

### Шаг 7. Возврат в нормальный режим

1. Открыто `msconfig` → вкладка **«Загрузка»**
2. Снята галочка с **«Безопасный режим»** → **Применить** → **ОК**
3. Выполнена перезагрузка — Windows 7 загрузилась в нормальном режиме

## Контрольные вопросы

### 1. Что такое безопасный режим Windows?

**Безопасный режим** — диагностический режим загрузки ОС Windows, при котором запускается только минимально необходимый набор компонентов: базовые драйверы устройств, стандартные системные службы. Программы из автозагрузки, сторонние драйверы и большинство служб не запускаются. Визуально: рабочий стол без фона, в углах надпись «Безопасный режим», разрешение экрана минимальное.

Используется для диагностики и устранения неполадок, которые невозможно исправить в нормальном режиме.

### 2. Параметры запуска безопасного режима

Безопасный режим можно запустить несколькими способами:

| Способ | Описание |
|---|---|
| **F8 при загрузке** | Нажать F8 до появления логотипа Windows → выбрать режим из меню |
| **msconfig** | Пуск → `msconfig` → вкладка «Загрузка» → галочка «Безопасный режим» |
| **Через параметры (Windows 10)** | Параметры → Обновление и безопасность → Восстановление → Особые варианты загрузки |

Варианты безопасного режима из меню F8:

- **Безопасный режим** — минимальный набор драйверов, без сети
- **Безопасный режим с загрузкой сетевых драйверов** — добавляется поддержка сети
- **Безопасный режим с поддержкой командной строки** — вместо графического интерфейса открывается командная строка

### 3. Отличия безопасного режима от чистой загрузки ОС

| Параметр | Безопасный режим | Чистая загрузка |
|---|---|---|
| **Цель** | Диагностика и восстановление при критических неполадках | Диагностика конфликтов стороннего ПО |
| **Загружаемые драйверы** | Только минимальные встроенные драйверы Windows | Все системные драйверы |
| **Службы** | Только критически важные службы Windows | Только службы Microsoft (сторонние отключены) |
| **Автозагрузка** | Полностью отключена | Отключена через msconfig/диспетчер задач |
| **Сеть** | Отключена (или ограничена) | Доступна |
| **Способ запуска** | F8 или msconfig → «Безопасный режим» | msconfig → вкладка «Общие» → «Выборочный запуск» |
| **Интерфейс** | Упрощённый (минимальное разрешение, без фона) | Обычный графический интерфейс |
| **Когда применять** | Система не загружается, вирусы, слетели драйверы | Система загружается, но нестабильно работает из-за стороннего ПО |
