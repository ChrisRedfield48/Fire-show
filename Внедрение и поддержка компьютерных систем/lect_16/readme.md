# Безопасный режим Windows

## Что такое безопасный режим?

**Безопасный режим (Safe Mode)** — способ загрузки ОС, при котором запускаются только минимально необходимые компоненты системы.

Используется, когда Windows начинает зависать или работать нестабильно, и нужно выяснить причину сбоя среди множества установленных программ и драйверов. За это его также называют **диагностическим режимом**.

---

## Особенности безопасного режима

- Загружаются только **основные службы и драйверы**, без которых Windows не запустится вовсе
- Все **второстепенные службы и программы** не запускаются
- Значительно повышается шанс успешной загрузки при нестабильной системе
- Упрощает выявление неполадок, связанных с компонентами Windows

---

## Что позволяет безопасный режим

| Задача | Описание |
|---|---|
| **Проверка на вирусы** | Вирусы из автозагрузки не запускаются → антивирус может их обнаружить и удалить |
| **Восстановление системы** | Запуск «Средства восстановления системы» в стабильных условиях |
| **Установка/обновление драйверов** | Загружены минимальные драйверы → легче устранить конфликты |
| **Диагностика** | Если в безопасном режиме проблем нет — причина в ПО; если есть — в железе |

---

## Виды безопасного режима

| Вид | Описание |
|---|---|
| **Безопасный режим** | Стандартный вариант: только необходимые службы и программы. Сетевые драйверы **не загружаются** — интернет недоступен |
| **Безопасный режим с загрузкой сетевых драйверов** | Дополнительно загружаются сетевые драйверы — **интернет доступен** |
| **Безопасный режим с поддержкой командной строки** | После запуска автоматически открывается **командная строка** (консоль) |
