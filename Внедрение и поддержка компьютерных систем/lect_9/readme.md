## 💡 Что такое драйвер

Драйвер — это специальная программа-посредник, которая позволяет операционной системе «понимать» подключённое оборудование и работать с ним.

**Без драйвера:**
- ОС не знает, как общаться с устройством
- Устройство не будет работать или будет работать некорректно

**Примеры устройств, требующих драйверы:**
- Видеокарты
- Принтеры и сканеры
- Сетевые адаптеры (Wi-Fi, Ethernet)
- Звуковые карты
- Контроллеры USB, Bluetooth и др.

## 📂 Где хранятся драйверы

В Windows драйверы находятся по пути:

```
C:\WINDOWS\SYSTEM32\
```

### Расширения файлов драйверов

| Расширение | Описание |
|------------|----------|
| `.sys` | Основной файл драйвера (системный) |
| `.drv` | Файл драйвера устройства |
| `.dll` | Библиотека, используемая драйвером |
| `.vxt` | Виртуальный драйвер |
| `.inf` | Информационный файл установки (содержит инструкции для инсталляции) |

## 🔍 Поиск драйвера для конкретного устройства

Три способа найти нужный драйвер:

### 1. С помощью утилит (например, AIDA64)

- Запустить программу AIDA64 (или аналог: CPU-Z, HWiNFO)
- Программа автоматически определит всё оборудование
- Можно узнать точное название устройства и найти драйвер на сайте производителя

### 2. Через Диспетчер устройств (стандартное средство Windows)

Путь к Диспетчеру устройств:
```
Пуск → Панель управления → Диспетчер устройств
```
или:
```
Win + X → Диспетчер устройств
```

- Устройства без драйвера отображаются с жёлтым значком ⚠️
- ПКМ по устройству → «Обновить драйвер» → автоматический или ручной поиск

### 3. Поиск по ID устройства

Каждое устройство имеет уникальный **Hardware ID**:

1. Открыть Диспетчер устройств
2. ПКМ по устройству → «Свойства» → вкладка «Сведения»
3. Выбрать «ИД оборудования» в выпадающем списке
4. Скопировать строку вида `PCI\VEN_XXXX&DEV_XXXX`
5. Вставить в поиск на сайте [devid.info](https://devid.info) или аналогах

## 📦 Установка пакета драйверов

Пакет драйверов — готовый набор для массовой установки (удобно при переустановке системы).

**Популярные сборки и утилиты:**
- **Driver Pack Solution** — автоматически определяет и устанавливает драйверы
- **Snappy Driver Installer** — аналог, работает офлайн
- Официальные утилиты производителей: Dell Update, ASUS DriverHub, Lenovo System Update и др.

**Порядок установки вручную:**
1. Скачать драйвер с официального сайта производителя
2. Запустить `.exe` установщик или использовать `.inf` через Диспетчер устройств
3. Перезагрузить компьютер (если требуется)

> ⚠️ **Совет:** всегда скачивайте драйверы с официальных сайтов производителя — это безопаснее, чем сторонние ресурсы.
