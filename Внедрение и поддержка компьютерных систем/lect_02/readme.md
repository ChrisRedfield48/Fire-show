## 💡 Общие сведения

> **Тестирование** — ряд мероприятий по испытанию объекта с целью установления соответствия характеристик требованиям и выявления дефектов.

**Результаты тестирования** — список выявленных несоответствий и дефектов.

**Методика испытаний** включает:
- перечень сценариев тестирования (test cases)
- подробное описание шагов
- ожидаемые результаты для каждого шага
- имитацию реальной эксплуатации системы

## 1️⃣ Классификация видов тестирования

### 🔲 По знанию внутренностей системы

| Вид | Описание |
|-----|----------|
| ⬛ **Чёрный ящик** (Black Box) | Тестировщик не знает внутреннего устройства; идеи исходят из поведения пользователей |
| ⬜ **Белый ящик** (White Box) | Основан на знании внутреннего устройства; доступ к исходному коду; обычно выполняется программистами |
| 🔲 **Серый ящик** (Grey Box) | Сочетает подходы чёрного и белого ящиков; информированное, ориентированное на пользователя |

### 🤖 По степени автоматизированности

| Вид | Описание |
|-----|----------|
| 👤 Ручное (Manual) | Тестировщик выполняет действия вручную |
| 🤖 Автоматизированное (Automated) | Выполняется скриптами и инструментами |
| 🔀 Полуавтоматизированное (Semiautomated) | Комбинация ручного и автоматического |

### 👥 По субъекту тестирования

| Вид | Описание |
|-----|----------|
| 🅰️ **Альфа-тестирование** | Имитация реальной работы штатными разработчиками или потенциальными пользователями; ранняя стадия |
| 🅱️ **Бета-тестирование** | Ограниченная версия для группы лиц; цель — минимизировать ошибки и получить обратную связь |
| 💨 **Smoke Testing** | Тестирование при приёмке |
| 🆕 **New Feature Testing** | Тестирование новых функциональностей |
| 🔁 **Regression Testing** | Регрессионное тестирование |
| ✅ **Acceptance Testing** | Тестирование при сдаче |

### 🕐 По времени проведения

- На этапах создания (обследования)
- На этапах технического сопровождения
- На этапах дальнейшего развития

### ➕➖ По критерию «позитивности» сценариев

| Вид | Описание |
|-----|----------|
| ✅ Позитивные | Проверка корректной работы при правильных входных данных |
| ❌ Негативные | Проверка обработки ошибок и некорректных данных |

### 🧩 По степени изолированности компонентов

| Вид | Описание |
|-----|----------|
| 🔬 **Модульное (компонентное)** | Проверка отдельных частей системы |
| 🔗 **Интеграционное** | Выявление дефектов взаимодействия подсистем |

## 2️⃣ Функциональное тестирование

> Проверяет соответствие реализованных функций требованиям и ожиданиям пользователя. Тестируется каждая функция и её взаимодействие в комплексе.

**Виды:**

| Вид | Что проверяется |
|-----|----------------|
| 🖥️ UI-тестирование | Пользовательский интерфейс |
| 🌍 Локализация | Адаптация для разных стран |
| 🔒 Безопасность | Защита от несанкционированного доступа |
| 🎯 Удобство использования | Простота и эффективность работы |
| 🔄 Совместимость | Работа в разных средах |
| 📦 Инсталляция | Процесс установки |
| 📄 Документация | Качество документации |

---

## 3️⃣ Нефункциональное тестирование

> Оценивает характеристики ПО, которые можно измерить — то есть **«как»** работает система.

| Вид | Что проверяется |
|-----|----------------|
| 📈 **Нагрузочное** (Load) | Поведение при ожидаемой нагрузке |
| 💥 **Стрессовое** (Stress) | Надёжность при превышении пределов нормального функционирования |
| ⚡ **Производительность** (Performance) | Скорость и эффективность работы |
| 🗄️ **Объёмное** (Volume) | Работа с большими объёмами данных |
| ⏱️ **Стабильность** (Stability) | Работа без сбоев длительное время |
| 🔧 **Восстановление** (Recovery) | Восстановление после сбоев |
| 🔐 **Безопасность** (Security) | Уязвимости и защита |
| 🙋 **Удобство** (Usability) | Простота освоения и эффективность |
| 🌐 **Локализация** (Localization) | Адаптация для других стран |

## 4️⃣ Детализация отдельных видов

### 🖥️ UI-тестирование

**Цель:** проверить лёгкость освоения, эффективность выполнения задач и защищённость от ошибок.

**Стандартные объекты проверки:**
`Text box` · `Text area` · `Numeric field` · `Drop down list` · `Combo box` · `Check box` · `Date field`

### 🌍 Тестирование локализации

- Перевод текстов
- Корректность форматов даты, времени, чисел, валют
- Соответствие культурным особенностям

### ⚡ Тестирование скорости и надёжности

> Оценка времени задержки в обработке как функции от приложенной нагрузки. Проводится в условиях, приближённых к реальной эксплуатации.

Включает: нагрузочное · стрессовое · производительности · объёмное · стабильности
