# Основы UNIX-подобных операционных систем

Конспект по материалу презентации. Linux и другие UNIX-подобные ОS строятся на общих принципах: единое дерево файлов, работа через команды, строгое разделение прав. Ниже — ключевые моменты с примерами.

---

## Файловая система: одно дерево, один корень

В отличие от Windows с его дисками `C:`, `D:`, в UNIX-подобных системах **нет отдельных дисков как корней** — всё подвешено к единственному корню `/`. Любой носитель, раздел или сетевой ресурс встраивается в это общее дерево.

Базовые каталоги, которые стоит знать:

- `/` — корень, начало всей файловой системы;
- `/home` — здесь живут личные каталоги пользователей (например, `/home/student`);
- `/media` — сюда система подключает съёмные носители: флешки, внешние диски, оптические диски;
- `/scr`, `/scr0` — каталоги для скратч-файлов (временных рабочих файлов, которые создаются программой на время вычислений и потом удаляются).

---

## Команды для файлов и каталогов

Весь повседневный набор для работы с файлами укладывается в несколько команд:

```
cd      переход между каталогами
ls      показать, что лежит в каталоге
cp      копировать файл или каталог
mv      переместить или переименовать
mkdir   создать каталог
rmdir   удалить (пустой) каталог
rm      удалить файл
```

Связка простая: `mkdir` создаёт, `ls` показывает, `cp`/`mv` перемещают и копируют, `rm`/`rmdir` убирают. На этих семи командах строится практически вся ручная работа с файлами в терминале.

## Регистр имеет значение

Это один из самых частых источников ошибок у новичков, пришедших из Windows.

**Linux различает заглавные и строчные буквы.** Для системы это разные символы, а значит — разные имена файлов.

Пример: в одном каталоге могут одновременно лежать
```
H2O.gjf
h2o.gjf
```
и это будут **два независимых файла**, а не один. Если набрать имя не в том регистре — система просто не найдёт файл и сообщит об ошибке.

Вывод для практики: при наборе команд и имён важно следить за регистром — `Document.txt`, `document.txt` и `DOCUMENT.TXT` для Linux совершенно разные вещи.

## Ускоряем работу в терминале

Командная строка кажется медленной, только пока не знаешь горячих клавиш. Основные:

| Клавиша | Что делает |
|---|---|
| ↑ / ↓ | листают историю введённых команд — не нужно перепечатывать заново |
| Tab | автодополнение: дописывает команду или имя файла по первым буквам |
| Tab (дважды) | если вариантов несколько — покажет их список |
| Ctrl + C | прерывает текущую команду, если она зависла или пошла не туда |

История и автодополнение экономят кучу времени: вместо набора длинного пути достаточно пары букв и `Tab`.

## Текстовый редактор nano

Когда нужно быстро отредактировать конфиг или текстовый файл прямо в терминале, используют `nano` — это простой консольный редактор без сложного интерфейса.

Полезное:
- выделенный мышью текст автоматически попадает в буфер обмена;
- вставка из буфера — сочетанием **Shift + Ins**.

---

## Файловый менеджер Midnight Commander

Для тех, кому удобнее видеть файлы списком в двух панелях (как в Far или Total Commander на Windows), есть **Midnight Commander**.

- запуск — команда `mc`;
- **Ctrl + O** — спрятать панели и временно вернуться к чистой командной строке (повторное нажатие возвращает панели);
- **F10** — выйти из программы.

По логике работы MC очень близок к Far Manager, так что если работал с ним под Windows — освоишься быстро.

## Практическое задание

Закрепляем теорию на практике:

1. Завести пользователя с логином `notuser` и паролем `123`.
2. В домашнем каталоге создать каталог `H2o` и текстовый файл `h2O.txt`.
3. Скопировать `h2O.txt` внутрь каталога `H2o`.
4. Вывести содержимое каталога `H2o`.

Команды для пунктов 2–4 (находясь в домашнем каталоге):

```bash
mkdir H2o
touch h2O.txt
cp h2O.txt H2o/
ls H2o
```

Тут специально заложена ловушка на регистр: каталог называется `H2o`, а файл — `h2O.txt`. Буквы те же, но регистр разный, и Linux воспринимает их как совершенно разные имена — ровно то, о чём говорилось в разделе про чувствительность к регистру.

---

## Главное в двух словах

- единое дерево файлов с корнем `/`, носители подключаются внутрь него (`/home`, `/media`, `/scr`);
- семь базовых команд закрывают всю работу с файлами: `cd`, `ls`, `cp`, `mv`, `mkdir`, `rmdir`, `rm`;
- **регистр важен** — `File` и `file` это разные файлы;
- терминал ускоряют история (↑↓), автодополнение (Tab) и прерывание (Ctrl+C);
- редактировать текст можно в `nano`, управлять файлами визуально — в Midnight Commander (`mc`).
