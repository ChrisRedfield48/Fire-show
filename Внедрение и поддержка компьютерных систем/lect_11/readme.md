## Практическая работа №13
**Тема:** Создание сети типа «компьютер - компьютер» в ОС Windows 10 [cite: 2]

### 1. Создание сети
Физическое соединение установлено путем подключения сетевого кабеля (витой пары) к сетевым картам двух компьютеров до характерного щелчка [cite: 24, 27, 28].

### 2. Настройка сети
Настройка произведена через Панель управления в разделе «Центр управления сетями и общим доступом» [cite: 32, 33]:
* **Компьютер №1:** Установлен статический IP-адрес `192.168.0.1` и маска подсети `255.255.255.0` [cite: 38, 39].
* **Компьютер №2:** Установлен IP-адрес `192.168.0.2`, маска подсети `255.255.255.0` и основной шлюз `192.168.0.1` [cite: 43, 44, 45].

### 3. Настройка рабочей группы и имени ПК
Для идентификации устройств в сети заданы следующие параметры [cite: 47]:
* **Компьютер №1:** Имя — `Comp1`, рабочая группа — `WORKGROUP` [cite: 50, 51].
* **Компьютер №2:** Имя — `Comp2`, рабочая группа — `WORKGROUP` [cite: 53, 54].

### 4. Общий доступ к ресурсам
* В дополнительных параметрах общего доступа включено сетевое обнаружение и общий доступ к файлам и принтерам [cite: 64].
* Отключена парольная защита для упрощения доступа в локальной сети [cite: 64, 65].
* Произведено «расшаривание» целевой папки через контекстное меню проводника («Предоставить доступ к – Отдельные люди») для пользователя «Все» с правами на чтение и запись [cite: 69, 70].

### 5. Проверка соединения
Проверка связи осуществлена в командной строке командой `ping 192.168.0.1` (или IP соседа) [cite: 76, 77]. Доступ к файлам проверен через ввод пути `\\Comp1` (или имени соседа) в адресной строке проводника [cite: 72, 73].

### Ответы на контрольные вопросы (№13)
* **Что такое IP-адрес?** Уникальный идентификатор устройства в сети [cite: 3, 4].
* **Типы IP-адресов:** IPv4 (32 бит) и IPv6 (128 бит) [cite: 12, 14, 15]. Бывают статическими и динамическими [cite: 8].
* **Отличия IPv4 от IPv6:** IPv6 решает проблему нехватки адресов за счет большего адресного пространства и использует шестнадцатеричную запись [cite: 13, 16, 17, 19].
* **Результат выполнения команды ping:** Подтверждение наличия связи и статистика задержек передачи пакетов [cite: 11, 78].

## Лабораторная работа №13а
**Тема:** Командные утилиты и их использование (getmac, netsh, net, pathping) [cite: 87, 89]

### Выполнение упражнений

**Упражнение 1. Справка**
Для получения справочной информации использовался параметр `/?` (например, `getmac /?`, `netsh /?`) [cite: 103, 108, 187].

**Упражнение 2. Утилита getmac**
Использована команда `getmac /v` для получения подробных данных [cite: 188]:
* Определены физические (MAC) адреса адаптеров (например, `54-04-A6-EB-10-2B`) [cite: 96, 188].
* Получены имена транспорта и названия сетевых адаптеров [cite: 102].

**Упражнение 3. Утилита netsh**
* Просмотрены конфигурации через `netsh dump` [cite: 189].
* Добавлен адрес: `netsh interface ipv4 add address name="Подключение по локальной сети" address=192.168.137.5 mask=255.255.255.0 gateway=192.168.137.1 gwmetric=1` [cite: 193].
* Изменен адрес на `192.168.137.3` командой `set address` [cite: 195].

**Упражнение 4. Утилита net**
* `net use`: просмотр подключенных сетевых дисков (например, диски `H:`, `L:`, `R:`) [cite: 156, 157, 196].
* `net user`: просмотр списка учетных записей [cite: 170, 196].
* `net share`: отображение списка общих ресурсов (диски `C$`, `ADMIN$`, `IPC$`) [cite: 165, 197].

**Упражнение 5. Утилита pathping**
Выполнена трассировка маршрута к узлу `172.21.66.57` для анализа потерь пакетов на промежуточных узлах [cite: 179, 180, 198].

**Упражнение 6. Настройка брандмауэра (netsh advfirewall)**
* Отключение: `set allprofiles state off` [cite: 127, 200].
* Включение профилей: `set domainprofile state on`, `set privateprofile state on` [cite: 129, 201].
* Политика: `set allprofiles firewallpolicy blockinbound,allowoutbound` [cite: 133, 202].
* Правило для приложения: `firewall add rule name="radmin server" dir=in action=allow program="C:\Path\To\radmin.exe" enable=yes` [cite: 150, 203].

### Ответы на контрольные вопросы (№13а)
1.  **Назначение netsh:** Универсальное средство управления сетевыми параметрами из командной строки [cite: 105, 205].
2.  **MAC-адрес:** Физический адрес адаптера; узнается через `getmac` [cite: 95, 206].
3.  **Назначение pathping:** Трассировка маршрута с детальной статистикой задержек и потерь [cite: 180, 182, 207].
4.  **Брандмауэр Windows:** Сетевой экран для фильтрации трафика по правилам (порты, IP, программы) [cite: 121, 208].
