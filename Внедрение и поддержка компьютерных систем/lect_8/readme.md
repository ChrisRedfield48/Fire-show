## 💾 Что такое BIOS

BIOS — это набор микропрограмм, «зашитых» в постоянную память материнской платы (микросхема **EEPROM**).

**Основные функции:**
- Обеспечивает доступ к аппаратной части компьютера
- Проводит самотестирование оборудования при включении
- Запускает операционную систему

Современная альтернатива классическому BIOS — **UEFI** (см. ниже).

## 🔍 Процедура POST

**POST** *(Power-On Self-Test)* — самотестирование при включении.

### Последовательность запуска:

```
Кнопка питания
      ↓
Блок питания (проверка напряжений)
      ↓
Центральный процессор
      ↓
Считывание микросхемы BIOS
      ↓
Процедура POST
      ↓
Загрузчик ОС
```

### 7 задач POST:

| № | Задача |
|---|--------|
| 1 | Инициализация CPU, ОЗУ, чипсета, видеоадаптера |
| 2 | Проверка контрольной суммы CMOS и батареи |
| 3 | Тестирование процессора и оперативной памяти |
| 4 | Инициализация периферии (клавиатура, мышь, диски) |
| 5 | Распределение ресурсов между устройствами |
| 6 | Поиск устройств с собственной BIOS |
| 7 | Вызов загрузчика операционной системы |

> 💡 При ошибке POST сигнализирует **звуковыми сигналами** или сообщением на экране.

## ⚡ UEFI

**UEFI** *(Unified Extensible Firmware Interface)* — современная замена классического BIOS.

Отличия от BIOS:
- Графический интерфейс с поддержкой мыши
- Поддержка дисков объёмом более 2 ТБ (GPT)
- Быстрее загружается
- Поддерживает технологию **Secure Boot**

## 🔔 Звуковые сигналы POST

### Award BIOS

| Сигнал | Значение |
|--------|----------|
| Нет сигнала | ❌ Неисправен или не подключён блок питания |
| Непрерывный | ❌ Неисправен блок питания |
| 1 короткий | ✅ Ошибок не обнаружено |
| 2 коротких | ⚠️ Незначительные ошибки (проверить шлейфы HDD) |
| 3 длинных | ⚠️ Ошибка контроллера клавиатуры |
| 1 длинный + 1 короткий | ❌ Проблемы с ОЗУ |
| 1 длинный + 2 коротких | ❌ Проблема с видеокартой |
| 1 длинный + 3 коротких | ⚠️ Ошибка инициализации клавиатуры |
| 1 длинный + 9 коротких | ❌ Ошибка чтения микросхемы ПЗУ |
| 1 длинный повторяющийся | ❌ Неправильная установка модулей памяти |
| 1 короткий повторяющийся | ⚠️ Проблемы с блоком питания (пыль) |

### Phoenix BIOS

Phoenix BIOS использует **трёхзначные коды** (паузы между группами сигналов):

| Код | Значение |
|-----|----------|
| 1-1-3 | Ошибка записи/чтения CMOS |
| 1-1-4 | Ошибка контрольной суммы BIOS |
| 1-2-1 | Неисправна материнская плата |
| 1-2-2 | Ошибка инициализации контроллера DMA |
| 1-3-1 | Ошибка регенерации ОЗУ |
| 1-3-3 | Ошибка тестирования первых 64 КБ ОЗУ |
| 3-1-1 | Ошибка инициализации второго канала DMA |
| 3-1-2 | Ошибка инициализации первого канала DMA |
| 3-2-4 | Ошибка контроллера клавиатуры |
| 3-3-4 | Ошибка тестирования видеопамяти |
| 4-2-1 | Ошибка системного таймера |
| 4-2-3 | Ошибка линии A20, контроллер клавиатуры |
| 4-2-4 | Ошибка защищённого режима (возможно, CPU) |
| 4-3-1 | Ошибка при тестировании ОЗУ |
| 4-3-4 | Ошибка часов реального времени |
| 4-4-1 | Ошибка тестирования последовательного порта |
| 4-4-2 | Ошибка тестирования параллельного порта |
| 4-4-3 | Ошибка тестирования математического сопроцессора |

## ⚙️ Настройка BIOS

### Вход в BIOS Setup

| Способ | Клавиши |
|--------|---------|
| Наиболее распространённый | `Del` или `F2` при перезагрузке |
| Зависит от производителя | см. инструкцию к материнской плате |

### Разделы главного меню

| Раздел | Описание |
|--------|----------|
| **Standard CMOS Features** | Дата, время, параметры дисков |
| **Advanced BIOS Features** | Порядок загрузки, кэш, прерывания |
| **Advanced Chipset Features** | Настройки чипсета |
| **Integrated Peripherals** | Встроенная периферия (USB, COM, LPT) |
| **Power Management Setup** | Управление питанием, спящий режим |
| **PnP/PCI Configurations** | Настройка PCI-устройств |
| **PC Health Status** | Температуры, скорости вентиляторов, напряжения |
| **Frequency/Voltage Control** | Разгон процессора и памяти |

### Управление в меню

| Действие | Клавиша |
|----------|---------|
| Сохранить и выйти | `F10` |
| Выйти без сохранения | `Esc` |
| Перейти в подраздел | `Enter` (если слева есть ▶) |

> ⚠️ **Внимание!** Разгон через BIOS может привести к нестабильной работе или поломке компьютера!

## 🔄 Сброс настроек BIOS

Если компьютер не запускается из-за неверных настроек BIOS:

1. Найти в меню BIOS пункт **«Load Optimized Defaults»** или **«Load Fail-Safe Defaults»**
2. Либо — аппаратный сброс: **вынуть батарейку CMOS** на 5–10 минут
3. Некоторые платы имеют кнопку **CLR_CMOS** на корпусе или материнской плате

> 😅 *«Если BIOS после такого заработал — значит случилось чудо»* © презентация

## 🔧 Обновление BIOS (перепрошивка)

### Способы обновления

| Способ | Безопасность | Описание |
|--------|-------------|----------|
| ✅ Встроенная утилита BIOS | Высокая | Например, **ASUS EZ Flash 2** |
| ⚠️ Утилита с дискеты/флешки | Средняя | Загрузочная флешка с прошивкой |
| ⚠️ Из операционной системы | Средняя | Утилита от производителя платы |

### Советы при перепрошивке

- 💾 **Обязательно** сохраните резервную копию текущей версии BIOS
- 🔌 На ноутбуке — **подключите питание** от сети (не на батарее!)
- 📋 **Прочитайте changelog** перед обновлением — если ваша проблема там не упомянута, обновлять не нужно
- ❌ **Не прерывайте** процесс перепрошивки (не выключайте питание!)
- 🔙 При неудаче — сразу восстанавливайте старую версию из резервной копии
