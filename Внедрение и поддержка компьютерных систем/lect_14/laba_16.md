# Практическая работа №16
## Групповые политики Windows 10

**Цель:** Изучить принципы работы с групповыми политиками Windows, научиться запускать и использовать редактор локальной групповой политики.

---

## Теоретическая часть

### Запуск редактора локальной групповой политики

```
Win + R → gpedit.msc → Enter
```

или через меню Пуск: ввести `gpedit.msc` и нажать Enter.

### Структура редактора

Окно редактора разделено на две панели:

| Панель | Содержимое |
|---|---|
| **Левая** | Древовидная иерархия категорий политик |
| **Правая** | Политики выбранной категории |

Две основные категории:

- **Конфигурация компьютера** — применяется ко всем пользователям, выполняется до входа в систему
- **Конфигурация пользователя** — применяется только к текущему пользователю после его входа

Каждая категория содержит три раздела:

| Раздел | Назначение |
|---|---|
| Конфигурация программ | Параметры приложений |
| Конфигурация Windows | Настройки системы и безопасности |
| Административные шаблоны | Параметры реестра через удобный интерфейс |

### Состояния политики

Каждая политика может иметь одно из трёх состояний:

- **Не задано** — политика не действует
- **Включено** — политика активна
- **Отключено** — политика действует, но её параметры отключены

### Поиск и фильтрация политик

Для поиска нужной политики среди ~3000 доступных:

1. Перейти в ветвь **Административные шаблоны → Все параметры**
2. Меню **Действия → Параметры фильтра**
3. Включить флажок **«Включить фильтры по ключевым словам»**
4. Ввести ключевое слово и выбрать режим совпадения:
   - **Любой** — хотя бы один из терминов
   - **Все** — все термины в любом порядке
   - **Точный** — точное совпадение фразы
5. Нажать **OK**, затем активировать кнопку **Фильтр**

## Ход выполнения работы

### Задание 1. Настройка окна безопасности Windows (Ctrl+Alt+Delete)

**Путь:** Конфигурация пользователя → Административные шаблоны → Система → Варианты действий после нажатия CTRL+ALT+DEL

Доступные политики для отключения кнопок:

| Политика | Отключаемая кнопка |
|---|---|
| Запретить изменение пароля | Сменить пароль |
| Запретить блокировку компьютера | Блокировать компьютер |
| Удалить диспетчер задач | Запустить диспетчер задач |
| Запретить завершение сеанса | Выйти из системы |

**Порядок выполнения:**
1. Открыть `gpedit.msc`
2. Перейти по указанному пути
3. Дважды щёлкнуть нужную политику → установить **«Включено»** → OK
4. Проверить результат: нажать Ctrl+Alt+Delete — кнопки исчезли

**Через реестр** (`HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System`):

```
DisableChangePassword = 0
DisableLockWorkstation = 0
DisableTaskMgr = 0
```

Для кнопки «Выйти из системы» — ключ `HKCU\...\Policies\Explorer`, параметр `NoLogoff = 1`.

---

### Задание 2. Настройка панели мест (диалоги Открыть/Сохранить как)

**Путь:** Конфигурация пользователя → Административные шаблоны → Компоненты Windows → Проводник Windows → Общее диалоговое окно открытия файлов

**Порядок выполнения:**
1. Открыть политику **«Элементы, отображаемые в панели мест»**
2. Установить **«Включено»**
3. В полях Элемент 1–5 ввести пути к нужным папкам (локальные или сетевые)
4. Нажать OK

**Через реестр** (`HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\comdlg32\Placesbar`):

```
Place0 = путь к папке
Place1 = путь к папке
...
Place4 = путь к папке
```

---

### Задание 3. Увеличение размера списка «Недавние документы»

**Путь:** Конфигурация пользователя → Административные шаблоны → Компоненты Windows → Проводник Windows

**Порядок выполнения:**
1. Открыть политику **«Максимальная длина списка "Недавние документы"»**
2. Установить **«Включено»**
3. В счётчике задать нужное число (от 1 до 9999)
4. Нажать OK

По умолчанию отображается 15 документов. При большом числе добавляются кнопки прокрутки.

---

### Задание 4. Включение диалога слежения за завершением работы

**Путь:** Конфигурация компьютера → Административные шаблоны → Система

**Порядок выполнения:**
1. Открыть политику **«Отображать диалог слежения за завершением работы»**
2. Установить **«Включено»**
3. В списке выбрать **«Всегда»**
4. Нажать OK

После включения при завершении работы появляется диалог с полями:

| Поле | Назначение |
|---|---|
| **Запланированное** | Флажок — было ли завершение запланировано |
| **Причина** | Список причин завершения работы |
| **Комментарий** | Текстовое описание события |

**Через реестр** (`HKLM\Software\Policies\Microsoft\Windows NT\Reliability`):

```
ShutdownReasonOn = 1
ShutdownReasonUI = 1
```

## Контрольные вопросы

### 1. Что такое групповые политики?

Групповые политики — совокупность параметров, используемых для конфигурирования рабочего окружения пользователя или компьютера. Это ключевое административное средство Windows, позволяющее управлять параметрами системы: от изменения внешнего вида интерфейса до ограничения прав пользователей. Редактор групповых политик (`gpedit.msc`) доступен только в версиях **Professional**, **Ultimate** и **Enterprise**.

### 2. Категории объектов групповых политик

| Категория | Описание |
|---|---|
| **Конфигурация компьютера** | Параметры применяются ко всей системе независимо от пользователя; вступают в силу до входа в систему |
| **Конфигурация пользователя** | Параметры применяются к конкретному пользователю; вступают в силу после его входа в систему |

### 3. Разделы групповых политик

Каждая из двух категорий содержит три раздела:

- **Конфигурация программ** — параметры, касающиеся приложений
- **Конфигурация Windows** — настройки системы и безопасности
- **Административные шаблоны** — параметры из реестра Windows в удобном интерфейсе (около 3000 политик)

### 4. Запуск групповых политик

Редактор локальной групповой политики запускается одним из способов:

```
Win + R → gpedit.msc → Enter
```

или через Пуск → ввести `gpedit.msc` → Enter.

Слово «локальная» означает, что редактируются политики локального компьютера, а не удалённого.
