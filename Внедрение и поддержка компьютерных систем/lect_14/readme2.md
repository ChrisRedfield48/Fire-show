# Групповые политики Windows

## Понятие групповой политики

**Групповая политика** — совокупность параметров, используемых для конфигурирования рабочего окружения пользователя или компьютера.

Это одно из ключевых административных средств Windows, предоставляющее широкие возможности по управлению параметрами системы: от изменения внешнего вида интерфейса до ограничения прав пользователей.

> ⚠️ Групповые политики не предназначены для домашних пользователей. Редактор групповых политик присутствует только в версиях **Professional**, **Ultimate** и **Enterprise**.

---

## Области применения

Групповая политика применяется к двум основным категориям сетевых объектов:

| Категория | Описание |
|---|---|
| **Пользователи** | Регламентирует окружение конкретного пользователя независимо от того, на каком компьютере он работает |
| **Компьютеры** | Определяет параметры системы для конкретного компьютера независимо от того, какой пользователь на нём работает |

---

## Что входит в окружение пользователя

- Конфигурация рабочего стола
- Доступные пользователю приложения
- Сценарии, выполняющиеся при входе/выходе из системы
- Права и разрешения на доступ к локальным ресурсам

Для управления этими разрешениями в доменах Windows используется **механизм групповых политик**.

---

## Объекты групповой политики (GPO)

**GPO (Group Policy Object)** — основной элемент групповой политики, выступающий в качестве самостоятельного элемента каталога.

- С каждым GPO связан глобальный уникальный идентификатор — **GUID**
- Структура многопользовательских ОС предполагает создание индивидуального окружения для каждого пользователя

---

## Запуск редактора групповой политики

```
Win + R → gpedit.msc → Enter
```

---

## Структура редактора

Настройки разделены на два раздела:

### Конфигурация компьютера
Параметры задаются для системы в целом, **вне зависимости** от того, под каким пользователем был совершён вход.

### Конфигурация пользователя
Настройки, относящиеся к **конкретным пользователям** ОС.

---

## Подразделы (есть в обоих разделах)

| Подраздел | Содержимое |
|---|---|
| **Конфигурация программ** | Параметры, касающиеся приложений на компьютере |
| **Конфигурация Windows** | Настройки системы и безопасности, другие параметры Windows |
| **Административные шаблоны** | Конфигурация из реестра Windows (те же параметры, что в `regedit`, но через более удобный интерфейс) |
