# Лабораторная работа №17
## Перенос данных из Windows 7 в Windows 10

**Цель:** Изучить процесс миграции пользовательских данных с Windows 7 на Windows 10 с помощью средства переноса данных Windows.

---

## Оборудование

- Компьютер с Windows 7 Professional (исходный)
- Виртуальная машина с Windows 10 Pro (целевой)

---

## Ход выполнения работы

### Часть 1. Подготовка данных на Windows 7

1. Создана папка **«For Transferring»** (Для переноса)
2. В Блокноте создан файл с текстом *«Со старого ПК»*, сохранён в папке `For Transferring` под именем **Data**
3. На рабочем столе создана папка **«Перенос»** (Файлы данных для переноса) — в неё будет сохранён файл миграции

---

### Часть 2. Экспорт данных через средство переноса (Windows 7)

**Путь:** Пуск → Все программы → Стандартные → Служебные → **Средство переноса данных Windows**

Порядок действий:

1. Нажать **Далее** в окне «Перенос файлов и данных Windows»
2. Выбрать способ переноса: **Внешний диск или USB-устройство флэш-памяти**
3. Выбрать: **Это мой исходный компьютер**
4. В окне выбора данных — снять флажки со всех учётных записей, затем нажать **Настройка** для своей учётной записи
5. Нажать **Дополнительно** → найти папку `For Transferring` → выбрать файл **Data** → **Сохранить**
6. Нажать **Далее** (пароль не вводить — перенос на тот же компьютер)
7. В качестве места сохранения выбрать папку **«Перенос»** на рабочем столе → **Сохранить**
8. Нажать **Далее** → **Далее** → **Закрыть**

> Размер переносимого файла Data: **~1 КБ**

Результат: в папке «Перенос» на рабочем столе создан файл миграции `.MIG`.

---

### Часть 3. Подготовка Windows 10

1. Запущена виртуальная машина с Windows 10
2. Установлены **утилиты виртуальной машины** (VMware Tools / VirtualBox Guest Additions), выполнена перезагрузка
3. Папка **«Перенос»** скопирована из Windows 7 в Windows 10

---

### Часть 4. Импорт данных на Windows 10

В Windows 10 встроенное средство переноса данных отсутствует. Для миграции используется папка **migwiz**:

1. Из папки с отчётами скопирована папка **migwiz** на рабочий стол Windows 10
2. Открыта папка `migwiz`, запущен исполняемый файл
3. В мастере переноса выбран файл `.MIG` из папки «Перенос»
4. Выполнен импорт данных

Процесс переноса данных завершён успешно.

---

## Контрольные вопросы

### 1. Все ли файлы были успешно перенесены?

Да, все файлы были успешно перенесены. Файл **Data** из папки `For Transferring` был корректно экспортирован средством переноса данных Windows 7 в файл `.MIG`, а затем импортирован на Windows 10 с помощью утилиты **migwiz**. После завершения переноса файл был доступен в указанном расположении на целевой системе.

### 2. Какие способы миграции (переноса) данных можно назвать?

| Способ | Описание |
|---|---|
| **Средство переноса данных Windows (migwiz)** | Встроенный инструмент Windows 7; создаёт файл `.MIG` с данными и настройками пользователя |
| **Внешний носитель** | Копирование файлов вручную на USB-флешку, внешний жёсткий диск или DVD |
| **Сетевая папка** | Передача данных по локальной сети между двумя компьютерами |
| **Облачное хранилище** | Загрузка данных в OneDrive, Google Drive и восстановление на новой системе |
| **Прямое кабельное подключение** | Перенос через USB-кабель типа «Easy Transfer» между двумя ПК |
| **Резервное копирование и восстановление** | Создание полного бэкапа системы и восстановление нужных файлов |
| **Виртуальная машина с общей папкой** | Монтирование папки хост-системы в гостевую ОС для прямого доступа к файлам |

## Вывод

В ходе лабораторной работы был изучен процесс переноса пользовательских данных с Windows 7 на Windows 10. На стороне Windows 7 использовалось встроенное «Средство переноса данных Windows» для создания файла миграции `.MIG`. Поскольку Windows 10 не имеет встроенного инструмента импорта, для восстановления данных применялась утилита **migwiz**, скопированная вручную. Файл был успешно перенесён на целевую систему.
