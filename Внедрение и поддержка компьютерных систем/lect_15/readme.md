# Резервное копирование и восстановление данных

## Что такое резервное копирование?

**Резервное копирование (backup)** — процесс создания копии данных на носителе, предназначенном для восстановления данных в оригинальном месте в случае их повреждения или разрушения.

**Причины потери информации:**
- Аппаратные сбои устройств
- Действия вредоносных программ и вирусов
- Ошибки пользователей

---

## Основы резервного копирования файловых ресурсов

В практически любой файловой системе существуют механизмы, облегчающие резервное копирование. При копировании файлов используются их **атрибуты**:

- **Дата и время последнего изменения** файла
- **Атрибут «Архивный»** (характерно для Windows) — указывает, что файл был изменён и требует резервного копирования

---

## Типы резервного копирования

### 1. Нормальный (Normal)
- Архивируются **все** файлы, отмеченные для архивации
- Используется для создания полных резервных копий
- Для восстановления достаточно восстановить **последний** сделанный архив

### 2. Добавочный (Incremental)
- Архивируются только файлы, изменённые **с момента последнего** копирования (нормального или добавочного)
- Атрибут «Архивный» после копирования **сбрасывается**
- Для восстановления нужно: восстановить последнюю **нормальную** копию → затем **все добавочные** копии последовательно

### 3. Разностный (Differential)
- Архивируются файлы, изменённые **с момента последнего нормального** архива
- Атрибут «Архивный» после копирования **не сбрасывается**
- Экономит место и ускоряет ежедневное копирование
- Для восстановления нужно: восстановить **нормальную** копию → затем **последнюю разностную**

### 4. Зеркальное копирование (Copy)
- Создаёт **полную** резервную копию всех файлов
- Атрибут «Архивный» **не изменяется** — план резервного копирования не затрагивается
- Для восстановления достаточно последнего архива

---

## Сравнительная таблица типов копирования

| Тип | Что копируется | Сбрасывает атрибут? | Восстановление |
|---|---|---|---|
| Нормальный | Все файлы | Да | Последний архив |
| Добавочный | Изменения с последнего копирования | Да | Нормальный + все добавочные |
| Разностный | Изменения с последнего нормального | Нет | Нормальный + последний разностный |
| Зеркальный | Все файлы | Нет | Последний архив |

---

## Точки мгновенного восстановления

- Копии создаются **не по расписанию**, а автоматически после **каждого изменения** данных
- При записи данных на диск они одновременно асинхронно записываются в другое место (обычно на другой компьютер по сети)
- Вносит дополнительную нагрузку на операции записи, но устраняет необходимость расписания
- Позволяет восстановить данные на **любой момент времени**

---

## Резервная копия состояния системы

Windows позволяет создать специальную резервную копию для восстановления работоспособности и всех настроек ОС.

**Что архивируется:**
- Системный реестр
- База данных зарегистрированных классов объектов
- Системные загрузочные файлы
- База данных служб сертификатов *(только на серверах со службой сертификатов)*
- База данных Active Directory и папка SYSVOL *(только на контроллерах доменов)*
