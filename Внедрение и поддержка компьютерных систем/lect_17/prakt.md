# Лабораторная работа №19
## Работа с журналами событий Windows

**Цель:** Изучить принцип работы журналов событий ОС Windows.

---

## Теоретическая часть

**Журнал событий Windows** — специальный лог, в который ОС автоматически записывает наиболее важные события: ошибки, предупреждения, а также успешные операции (установка программ, подключение к сети и т.д.).

**Назначение:** сбор данных для устранения неисправностей в работе системы, программного обеспечения и оборудования.

**Физическое расположение:** файлы в формате `.evtx` хранятся в папке:
```
%SystemRoot%\System32\winevt\Logs
```
Файлы имеют **бинарный формат** — открыть Блокнотом нельзя.

**Утилита просмотра:** `eventvwr.msc`

```
Win+R → eventvwr.msc
```
или: Панель управления → Администрирование → **Просмотр событий**

### Структура окна eventvwr

| Область | Содержимое |
|---|---|
| Левая колонка | Журналы, отсортированные по разделам |
| Средняя часть | Список событий выбранной категории |
| Правая колонка | Доступные действия с журналом |
| Нижняя панель | Подробные сведения о конкретной записи |

### Разделы журнала

- Настраиваемые события
- **Журналы Windows** *(основной раздел для диагностики)*
- Журналы приложений и служб
- Подписки

### Категории раздела «Журналы Windows»

| Категория | Содержимое |
|---|---|
| **Система** | События от системных компонентов — драйверов и модулей Windows |
| **Приложения** | Записи от установленных программ; помогает найти причину сбоя ПО |
| **Безопасность** | Входы в систему, управление учётными записями, изменение прав доступа, запуск процессов |
| **Установка** *(доп.)* | События установки компонентов Windows |
| **Перенаправленные события** *(доп.)* | События, собранные с других компьютеров |

## Ход выполнения работы

### Шаг 1. Запуск журнала событий

1. Нажато `Win+R`, введено `eventvwr.msc` → Enter
2. Открылась утилита «Просмотр событий»
3. Изучена структура журнала: разделы в левой панели, список событий в центре, действия справа

---

### Шаг 2. Фильтрация журнала «Система»

1. В левой панели выбрано: **Журналы Windows → Система**
2. В правой панели нажато **«Фильтр текущего журнала»**
3. Установлены параметры фильтра:
   - Дата: **Последние 7 дней**
   - Уровень событий: **Критические**, **Ошибки**, **Предупреждения**
4. Нажато **ОК**

> **Количество событий после применения фильтра:** ~47 событий *(пример)*

---

### Шаг 3. Сохранение фильтра

1. В правой панели нажато **«Сохранить фильтр в настраиваемом представлении»**
2. Задано имя представления: **«Система — Ошибки»**
3. Нажато **ОК**
4. Сохранённый фильтр появился в левой панели в разделе «Настраиваемые представления»

---

### Шаг 4. Фильтр для журнала «Безопасность» (самостоятельно)

1. В левой панели выбрано: **Журналы Windows → Безопасность**
2. Нажато **«Фильтр текущего журнала»**, установлены параметры:
   - Дата: **Последние 30 дней**
   - Уровень событий: **Предупреждения**, **Сведения**
3. Нажато **ОК**
4. Фильтр сохранён с именем: **«2ИСП9-1 Безопасность»**

---

### Шаг 5. Привязка задачи к событию

1. В отфильтрованном журнале «Безопасность» выбрано нужное событие (согласно таблице вариантов)
2. В правой панели «Действия» нажато **«Привязать задачу к событию»**
3. В мастере настройки задачи:
   - **Windows 7:** выбрано действие **«Отобразить сообщение»**
   - Установлена галочка **«Открыть окно Свойства при нажатии кнопки Готово»**
   - На вкладке **«Общие»** настроены общие параметры задачи
   - На вкладке **«Параметры»** настроены дополнительные параметры
4. Нажато **Готово**

---

### Шаг 6. Очистка журнала «Установка»

1. В левой панели выбрано: **Журналы Windows → Установка**
2. Кликнуто ПКМ → выбрано **«Очистить журнал»**
3. Журнал «Установка» очищен

---

### Шаг 7. Настройка службы «Журнал событий Windows»

1. Нажато `Win+R`, введено `services.msc` → Enter
2. В списке найдена служба **«Журнал событий Windows»**, двойной клик
3. В свойствах настроено:
   - Вкладка **«Общие»**: Тип запуска → **«Вручную»**
   - Вкладка **«Восстановление»**: при первом и втором сбое — **«Перезапуск службы»**; при последующих — **«Перезагрузка компьютера»**
4. Нажато **Применить** → **ОК**

## Контрольные вопросы

### 1. Что такое журналы событий Windows?

**Журнал событий Windows** — встроенный инструмент ОС для автоматической регистрации значимых событий: системных ошибок, предупреждений, сведений об успешных операциях. Просматривается через утилиту `eventvwr.msc`. Используется администраторами и пользователями для диагностики неполадок в работе системы, программ и оборудования. В журнал попадают как сбои, так и штатные события — установка ПО, вход пользователя, подключение устройств.

### 2. Физическое расположение журнала Windows

Файлы журналов хранятся в формате `.evtx` по пути:

```
%SystemRoot%\System32\winevt\Logs
```

Обычно это: `C:\Windows\System32\winevt\Logs`

Файлы имеют бинарный формат и не открываются текстовыми редакторами — для просмотра используется только `eventvwr.msc`.

### 3. Основные и дополнительные категории журнала Windows

**Основные категории:**

| Категория | Описание |
|---|---|
| **Система** | События системных компонентов: драйверов и модулей Windows |
| **Приложения** | Записи от установленных программ; помогает найти причину сбоя ПО |
| **Безопасность** | Входы/выходы пользователей, изменение прав доступа, запуск и остановка процессов |

**Дополнительные категории:**

| Категория | Описание |
|---|---|
| **Установка** | События установки и обновления компонентов Windows |
| **Перенаправленные события** | События, собранные с удалённых компьютеров в сети |
