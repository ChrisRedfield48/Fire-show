# Журналы событий Windows

## Что такое журнал событий?

**Журнал событий Windows** — средство, позволяющее программам и самой системе Windows регистрировать и хранить уведомления в одном месте. В журнале фиксируются все ошибки, информационные сообщения и предупреждения программ.

---

## Основные виды журналов

| Журнал | Содержимое |
|---|---|
| **Приложений** | Данные о работе приложений и программ. Записи создаются самими приложениями — состав событий определяют разработчики |
| **Безопасности** | Успешные и неудачные попытки входа в систему, создание/открытие/удаление файлов и объектов. Состав событий определяет администратор через настройки аудита |
| **Системы** | События от компонентов ОС Windows: сбои при загрузке драйверов, ошибки системных компонентов при запуске |

---

## Типы событий

| Тип | Значок | Описание |
|---|---|---|
| **Ошибка** | 🔴 Красный круг с белым крестом | Серьёзные проблемы: потеря данных или функциональности (например, сбой загрузки службы) |
| **Предупреждение** | 🟡 Жёлтый треугольник с «!» | Не критично сейчас, но может привести к проблемам (например, мало свободного места на диске) |
| **Уведомление (Сведения)** | 🔵 Белый круг с синей «i» | Успешное завершение действия — загрузка драйвера, запуск службы |
| **Аудит успехов** | ✅ | Успешное действие в сфере безопасности (например, успешный вход пользователя) |
| **Аудит отказов** | ❌ | Неудачное действие в сфере безопасности (например, неудачная попытка доступа к сетевому диску) |

---

## Важно

- Служба журналов событий **запускается автоматически** при старте Windows
- Журналы **приложений** и **системы** доступны всем пользователям
- Журнал **безопасности** доступен только **системному администратору**
- По умолчанию запись в журнал безопасности **отключена** — включается через **Групповую политику**
