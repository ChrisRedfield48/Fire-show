## 📌 1. Предисловие к курсу

Компьютерные сети и сетевые технологии прочно вошли практически во все сферы современной жизни и играют особо важную роль в информационных технологиях. Данное учебное издание предлагает материалы конспекта лекций, читаемых для студентов специальности «Информационные системы и технологии (в здравоохранении)».

**Методология изучения:**
* Материал охватывает все темы курса и построен в соответствии с нисходящим подходом к изучению дисциплины. 
* Изложение начинается с общей терминологии и освоения верхних уровней стека протоколов.
* Продолжается рассмотрением тем в соответствии с моделью OSI и движением к нижнему, физическому уровню.

**Практическая ценность курса:**
* Курс лекций позволяет повторить материал, необходимый для успешного выполнения лабораторных и контрольных работ. 
* Особое внимание уделяется вопросам, связанным с IP-адресацией, маршрутизацией в сетях и основными службами сети Интернет. 
* Рекомендуемые материалы могут служить отправной точкой для подготовки к сдаче экзамена по дисциплине или углубленного изучения отдельных вопросов.

## 🎓 2. Лекция № 1. Введение в компьютерные сети

### 2.1. Базовые концепции и определения



Для понимания архитектуры информационных систем необходимо освоить базовый категориальный аппарат:
* **Сеть (Network):** взаимодействующая совокупность объектов (узлов, nodes).
* **Компьютерная сеть (сеть передачи данных, Computer Network):** это совокупность связанных между собой компьютеров, телекоммуникационного оборудования и программного обеспечения, обеспечивающая информационный обмен между компьютерами в сети.
* **Узел компьютерной сети:** хост (host) или конечная система (end system). Конечные системы соединяются между собой при помощи линий связи и коммутаторов пакетов.
* **Пакеты (Packets):** отдельные порции информации, передаваемые по сети.

**Структурный состав компьютерной сети:**
* Компьютеры, соответствующие назначению компьютерной сети;
* Коммуникационное оборудование;
* Сетевые операционные системы (NOS – Network Operation System);
* Сетевые приложения.

### 2.2. Архитектура телекоммуникаций

* **Телекоммуникации:** (греч. *tele* – вдаль, далеко и лат. *communicatio* – общение) – это передача и прием любой информации (звука, изображения, данных, текста) на расстояние по различным электромагнитным системам.
* **Телекоммуникационная сеть (ТС):** это система технических средств, посредством которой осуществляются телекоммуникации.

Телекоммуникационную сеть условно принято разделять на две основные подсистемы (см. рис. 1.1):
1. 🔀 **Коммуникационная сеть:** предназначена исключительно для передачи данных.
2. 💾 **Информационная сеть:** предназначена для обработки, хранения и передачи данных и создается подключением к коммуникационной сети абонентских систем.



**Трехуровневый состав телекоммуникационных сетей (см. рис. 1.2):**
1. **Сети доступа (access network):** нижний уровень ТС, к которому подключаются «конечные узлы» – оборудование пользователей.
2. **Магистральная сеть (core network или backbone):** объединяет сети доступа и выполняет транзит трафика по высокоскоростным каналам.
3. **Информационные центры (data centers или service control point):** собственные информационные ресурсы сети, на основе которых выполняется обслуживание пользователей.

### 2.3. Классификация компьютерных сетей

Сети классифицируются по множеству признаков: по территориальному признаку, по масштабу производственного объединения, по технологии передачи, по принципу организации обмена данными между абонентами, по типу среды передачи данных, по принципу организации иерархии компьютеров и т.д.

#### 🌍 А. По территориальному признаку
* **Локальные сети (ЛС, LAN – Local Area Network):** сеть, включающая узлы в пределах одного помещения, здания или небольшой территории. *(Примеры: сеть в лаборатории университета, сеть главного корпуса).*
* **Региональные (городские) сети (MAN, Metropolitan Area Network):** сети для обслуживания территории района, крупного города или региона. *(Пример: городские сети провайдера (например, МТС)).*
* **Глобальные сети (ГС, WAN – Wide Area Network):** сети, объединяющие компьютеры, находящиеся в различных городах и странах. *(Примеры: Интернет, сеть FidoNet).*

#### 🏢 Б. По масштабу производственного подразделения
* Сети отделов (рабочих групп);
* Сети кампусов (campus networks) и домовые сети;
* Корпоративные сети (enterprise-wide networks).

#### ⚡ В. По технологии передачи данных
* **Вещание (broadcast):** основана на разделяемых каналах передачи данных (shared channel).
* **Соединение «точка-точка» (point-to-point):** передача данных ведется между двумя абонентами.

#### 🔀 Г. По принципу организации обмена данными (коммутации)
* Сети на основе коммутации каналов;
* Сети на основе коммутации **пакетов (packet switching)** – доминирующая технология сегодня;
* Сети на основе коммутации сообщений.

#### 🔌 Д. По типу среды передачи данных
* **Проводные (wired):** коаксиальный кабель, витая пара, оптоволокно.
* **Беспроводные (wireless):** радиочастоты, инфракрасный диапазон.

#### 🖥️ Е. По принципу организации иерархии компьютеров
* **Одноранговые (Peer-to-Peer Network).**
* **Клиент-серверные (с выделенным сервером, Dedicated Server Network).**

### 2.4. Главное назначение сетей

Глобально компьютерные сети создаются для решения двух фундаментальных задач:
1. **Обеспечение доступа к разделяемым ресурсам.**
2. **Межперсональная коммуникация.**

**Разделяемый (сетевой) ресурс (network share)** – это устройство или информация, к которой возможен удалённый доступ с другого компьютера.

| Услуги доступа к ресурсам | Услуги межперсональной коммуникации |
| :--- | :--- |
| • Удаленный доступ (Remote Login) | • Электронная почта (e-mail) [1:1] |
| • Передача файлов (File Transfer) | • Списки рассылки (news group) [1:n] |
| • Удаленный вызов процедур (RPC – Remote procedure call) | • Телеконференции [n:n] |
| • Совместное использование устройств | • Системы электронных бюллетеней (BBS) |
| | • Видеоконференции и т.д. |

### 2.5. Историческая справка


* **60-е годы:** DARPA ведет проект по объединению двух удаленных мейнфреймов. Первые глобальные связи компьютеров, эксперименты с пакетными сетями, начало передачи голоса по телефонным сетям в цифровой форме.
* **1969 год:** Создание сети ARPANET (Advanced Research Project Agency Network) Министерством обороны США. США инициировала работы по объединению в единую сеть суперкомпьютеров оборонных и научно-исследовательских центров – сеть ARPANET (см. рис. 1.3–1.4).

## 📖 3. Словарь терминов (Глоссарий)
*Специально для подготовки к экзаменам все определения вынесены в отдельный блок:*

* **Клиент (client)** – компьютер или программа, запрашивающая услуги.
* **Коммутация** – технология выбора направления и организации передачи данных в сетях, имеющих несколько альтернативных маршрутов.
* **Распределенная программа** – программа, состоящая из нескольких взаимодействующих частей, выполняемых на разных компьютерах.
* **Сервер (server)** – компьютер или программа, предоставляющая услуги другим компьютерам или программам (клиентам).
* **Сетевой трафик (traffic)** – передаваемые по сети информационные потоки.
